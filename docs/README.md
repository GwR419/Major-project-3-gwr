## To publish with GitHub Pages
1. Create a new repo on GitHub (or use an existing one).
2. Upload index.html and styles.css to the repo (same folder level).
3. Go to Settings -> Pages -> Deploy from a branch -> select `main` and `/ (root)`.
4. GitHub will give you a live URL, usually:
   https://<your-username>.github.io/<repo-name>/
